## What I work on
- **Agentic AI:** tool-using agents and multi-agent systems that run real workflows end to end: verified extraction, guarded writes to external systems, validation and failure handling, human-in-the-loop approval
- **LLMs:** multi-agent RAG, LoRA/QLoRA fine-tuning, LLM judges and evals, MCP servers, LLM analytics pipelines
- **Computer vision at the edge:** Jetson/ARM, TensorRT, ONNX quantization (40% faster inference at 95% accuracy)
- **Down to the metal:** custom CUDA kernels on NVIDIA Blackwell, ~1.2x faster than native PyTorch ops at exact FP32 precision
- **Measurement:** A/B testing, regression and time-series analysis, 10 TB+ data pipelines
